# 22: D1 交付 CLI、版本和环境探针

Status: ready-for-agent

Blocked by: None (can start immediately)

## 交付内容

组员在登录节点就能核对二进制和启动方式，在计算节点通过正常 MPI 入口核对设备与通信环境，并用退出码定位失败。

## 验收条件

- [ ] 在空作业目录并屏蔽 CUDA 设备，分别调用 `--help` 与 `--version`，均正常退出。帮助给出实际支持的启动方式，版本能追溯到源码提交或候选包身份。无需创建科学输入或输出。
- [ ] 使用普通单 rank 和 MPI 启动入口从有效输入完成短作业。运行 GPU/MPI 自检并记录进程数、设备映射与所选通信后端。已有的无参数模拟启动方式可继续使用。
- [ ] 覆盖未知选项、模拟缺输入、GPU/绑定或后端预检失败。帮助、成功自检和失败状态各有稳定的退出码及明确诊断，MPI 失败时全体结束。
- [ ] 交付可复核的命令、环境条件、标准输出/错误与退出码，并核对构建版本与候选元数据一致。
