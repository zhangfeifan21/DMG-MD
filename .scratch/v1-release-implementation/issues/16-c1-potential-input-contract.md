# 16: C1 统一势输入与诊断

Status: ready-for-agent

Blocked by: 15

直接前置工单为[15 C0 统一求力接口并保持 NEP 兼容](15-c0-nep-force-interface.md)。

## 交付内容

用户用同一条 potential 声明载入支持的势，程序按势头和元素顺序分派，对格式错误或尚无实现的势给出可操作的启动诊断。

## 验收条件

- [ ] 从实际输入核对 NEP、LJ 和 EAM/alloy 势头识别、元素数和顺序。已实现的 NEP 正常运行。已识别但尚无求力实现的类型获得明确诊断，后续 C2、C3 可复用同一输入格式。
- [ ] 只有 EAM/alloy 接受可选最大邻居数。无参数取 400，接受 1 和 1024 两个边界。0、1025、非整数、额外参数以及给其他势指定该参数的作业均报告具体错误。
- [ ] 用缺项、重复元素或字段、多余或未知 token、结构元素无法映射和未知势头覆盖负例。记录用户输入、错误位置或条件、退出码及首步前的行为。
- [ ] 在已实现势上复跑正例，保留原有元素顺序、输出精度和 NEP 短程兼容性，交付正反例清单与可复现命令。
