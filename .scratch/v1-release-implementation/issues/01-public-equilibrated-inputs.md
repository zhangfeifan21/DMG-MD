# 01: 冻结碳、水、铜三套公开输入

Status: ready-for-agent

Blocked by: None (can start immediately)

## 交付内容

组员能从公开来源重建三种生产规模输入，并从同一份末态快照分别启动不同引擎的 NPT 作业。

可立即用已有短算例试规模和制备快照。正式冻结时采用输入决策单认可的最终规模、平衡依据与版本。

## 验收条件

- [ ] 交付金刚石碳（NEP4-C）、致密水（对应水 NEP）和 FCC 铜（NEP4-ZBL）的原始出处、生成命令、放大倍数、原子数、种子及势文件身份。区分铜的 NEP 试用势与力场开发用的 EAM/alloy。
- [ ] 在最终盒与规模完成平衡。每种材料保存平衡过程、平衡判定、盒、原子顺序、元素、质量、坐标和非零初速度，复读所得快照并核对哈希。早期 20 步运行只作为先导记录。
- [ ] 为三项外部对标逐材料登记共同能容纳且适合分区的规模。记录尝试过的卡数、启动或容量证据，保留容量不重叠的工况及原因。规模与平衡判定提交给现有输入决策单确认。
- [ ] 冻结物理步长、步数、温压和耦合参数、所需输出及频率。由另一作业目录复用同一盒、速度和势运行短作业，并留存输入清单、摘要和生成环境。
