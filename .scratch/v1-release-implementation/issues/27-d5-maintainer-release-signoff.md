# 27: D5 维护者签署发布结论

Status: ready-for-agent

Blocked by: 26

直接前置工单为[26 D4 从候选源码包独立复建并核对证据](26-d4-reproduce-release-candidate.md)。

## 交付内容

维护者可以对同一版本的 G-A、G-B、G-C、G-D 和交付件作出逐项可追溯的发布决定。代理可准备签署材料，最终决定由维护者本人记录。

## 验收条件

- [ ] 逐项核对门槛、候选身份、适用范围、原始记录及审阅人。确认 26 已汇齐 L20 的三份 SCR 科学判定、最终默认策略和正式 NPT 报告、单列的四引擎 NVE 表，以及同一八卡机覆盖全部 rank/后端的长程 release。对任何缺项记录影响。
- [ ] 逐项核对最终版本、源码包校验和、各势示例、部署指南、许可证与第三方声明、发布说明及已知限制。写清单节点证据的边界以及后续能力范围。
- [ ] 维护者记录姓名或可核验标识、日期、候选身份和同意发布或暂缓的决定。暂缓时记录阻塞、负责人和复验条件，发布状态随签署决定更新。
- [ ] 区分签署记录、正式 tag 与对外发布授权。该工单的完成凭据是可核对的维护者决定，涉及推送或对外分发的动作按维护者授权执行。
