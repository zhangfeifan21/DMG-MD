# 13: DMG-MD 自身强扩展与 DN5 缓存选择

Status: ready-for-agent

Blocked by: 03, 05, 09

直接前置工单为[03 验证变盒、输出与跨卡重启](03-box-output-cross-rank-restart.md)、[05 用短作业验证配对计时](05-paired-job-timing.md)、[09 完成三材料 SCR 科学验收](09-three-material-scr-validation.md)。

## 交付内容

组员能在固定规模判断加卡的收益，维护者能根据同卡数实测与科学证据选择局部 NPT 的默认缓存策略。

本单使用计时决策的预注册部分安排采样。该决策关于默认缓存的部分随后接收这里的实测数据和采纳意见。

## 正式采样条件

首个正式样本前，冻结预热、重复数、配对交错顺序和区间算法。确认三种 SCR 科学验收与真实多卡分派回归均已通过，单节点每批独占四张 L20，串行执行配对作业。固定并记录 GPU 集合、时钟与功率设置、CPU 总预算、NUMA 放置、输出介质及物理任务。每条轨迹从启动计到约定输出写完。

## 验收条件

- [ ] 以同一候选和每种材料的同一规模分别测 DMG-MD 1/2/4 卡，固定物理工作、输出与对应设置，记录实际分派和两种控压的可比状态。用绝对时长计算 `S(P) = T(DMG,1) / T(DMG,P)`、`E(P) = S(P) / P`，附配对区间与 GPU·小时。
- [ ] 按相同卡数、后端、输入、输出频率分开测显式内部 `off`（全量复制）、`rebuild`（强制重建）、`affine`（形变复用）。记录正确性、缓存复用或重建计数和完整轨迹用时，剖析运行另列。
- [ ] 按材料交付固定规模的强扩展表与同卡缓存对照表。单卡无法容纳时给容量证据并留空相应强扩展分母。区间跨 1 时如实记为差异未分辨。
- [ ] 依据实测完整轨迹、区间和适用条件，在 DN5 决策中记录维护者采纳的局部默认策略或保守选择的理由。用普通多卡命令复验采用后的局部分派，并标记需要在最终配置上复核的外部计时格。
- [ ] 原始记录含输入与二进制哈希、实际设备与绑定、退出码、末帧和每次配对值。审阅者能复算绝对时长、区间及 GPU·小时。各方向的性能结果均予报告，验收不设固定胜负或最低提速倍率。
