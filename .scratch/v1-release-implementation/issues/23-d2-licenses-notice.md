# 23: D2 核查许可证与第三方分发范围

Status: ready-for-agent

Blocked by: None (can start immediately)

## 交付内容

维护者能判断候选源码包中每个复用内核、示例势和第三方组件应如何交付，组员能依法取得运行示例所需的材料。

## 验收条件

- [ ] 逐项清点项目源码、复用的 GPUMD 内核、第三方代码/补丁、外部依赖、示例及其势文件。登记出处、版本或哈希、对应许可文本和需要保留的声明，标明仅站点使用的二进制或数据。
- [ ] 为候选随附物准备 LICENSE、NOTICE 及适用的许可证副本，核对署名、来源、修改说明和所需再分发条件。把仅作测试参考的 GPUMD、MatPL、WPE 等与实际装包清单逐项核对。
- [ ] 对分发权限未确认的组件或势列出跟进项。适合由组员自行取得的材料给出原始来源、身份校验和放置说明。候选随附清单只列分发依据已确定的内容。
- [ ] 以清单逐项对照拟交付件和三类势示例，让审阅者能从每个文件追溯来源与分发决定。需要维护者作出的决定保留确认记录。
