# 局部 NPT affine 缓存的有限精度证明

当各向同性盒改变时，当前求力需要的每条边是否仍在上次重建的邻居表和位置 halo 内，取决于盒形变、原子位移以及建表与求力的舍入误差。本证明给出允许复用这些数据的充分条件。结论限于正对角、全周期盒及 NEP 大盒的 `affine` 路径。普通路径和 NEP 数学沿用原实现。

先检查建表时的整数索引和内存访问安全。如果检查失败，须在建表前拒绝，或另选安全的建表器。再次调用同一建表器不能消除越界。通过后才能检查复用条件。任一复用前提未满足时，不能引用本证明。GPU 数值验收与统计验收另有独立记录。

## 记号和前提

将盒长、位置和截断半径存储的二进制值视为精确输入。下面分别用 u 和 v 表示双精度和单精度的单位舍入误差，用 γk 累计 k 次运算的相对误差。`u=2^-53`、`v=2^-24`，`γk(t)=kt/(1-kt)`。假设 CPU 和 CUDA 的 double、float 为 IEEE 754 最近舍入，除法、平方根正确舍入，允许逐次运算或 FMA；GPU 对 float 次正规数 flush-to-zero 也在下界内。不得启用破坏这些界的 fast-math 或近似除法。若生成代码不满足此假设，此证明不适用。

对参考盒和当前盒都施加以下尺度限制。

- 六个轴长 `L` 均在 `[10^-3,10^6]`，其中的最大值记为 `Lmax`。
- `R*` 是所有实际单边 force 和 dependency cutoff 的上界，范围也为 `[10^-3,10^6]`。`s=skin=1`。
- 建表器实际使用二进制半径 `B=fl(rc+s)`，其中 `rc` 是 NEP 建表器实际的 `rc_radial_max`，要求 `1≤B≤10^6`。证明必须使用这个 `B`。`R*=state.d_dep-s` 的反算可能有 1 次舍入，这项误差计入 `E_force`。
- 当前和参考坐标分别位于对应的 `[0,L]`，记录周期跨越的整数 image 的绝对值严格小于 `10^6`。
- 半盒长度必须留出误差余量，满足 `Lmin/2 > R*+s+E`，其中 `E=256 ε32 Lmax=512 v Lmax`。主机在作乘加和比较时向保守方向取下界。实现还须保守处理这项检查本身的舍入。

上述条件限制尺度和表示。运行时仍须检查非有限值、通信、布局代次及溢出。

**整数索引须在建表前安全。** 首次建表、以后每次建表，以及候选盒提交前，都要做此检查。令 `h=B/2`，对每轴向上保守地计算 `Nhat=ceil(2L/B)+2`。要求 `Nhat` 及三个 `Nhat` 的乘积都不大于 `INT_MAX/4`。检查过程本身也不得溢出。

于是实际 bin 数 `n` 不超过 `Nhat`。相邻 cell 的偏移满足 `|i|,|j|,|k|≤2`，各 `n≥4`。`neighbor.cu` 中的 `cell_id + k*nx*ny + j*nx + i`、随后的单次周期修正和线性索引，各步都可用 int 表示。

只检查总 bin 数会漏掉偏移加法溢出。例如 `(nx,ny,nz)=(2000,2000,536)` 的乘积为 2,144,000,000，小于 `INT_MAX`。但最大 cell 索引加上 `2*nx*ny` 就会越界。即便索引安全，内存分配失败仍须报错。

## Box、cell 和 ±2 扫描

先从盒矩阵求 cell 边界的位置。对正对角盒，`Box::get_inverse` 先乘两个对角元，再除以按 `Lx*(Ly*Lz)` 计算的行列式。`get_volume`、`get_area` 和 `get_num_bins` 分别再算体积、面对角元乘积的平方、开方、厚度除法和 `floor(thickness/h)`。长度范围使乘积、面积平方及其逆的所有非零中间值为正常 double，且远离溢出。零的非对角项精确为零。逐操作计数给出下表的宽松界。FMA 合并零项不会增加操作次数。

| 数量 | 相对精确值的界 |
|---|---|
| 体积 `Lx*(Ly*Lz)` | `γ2(u)` |
| 面积 `sqrt(fl(fl(La*Lb)^2))` | `γ3(u)` |
| inverse 对角元 `(La*Lb)/volume` | `γ4(u)` |
| 厚度 `volume/area` | `γ6(u)` |
| `thickness/h`，及 `rc_inv=1/h=2/B` | 分别 `γ7(u)`、`γ1(u)` |
| cell 运算 `fl(fl(fl(inv*x)*thickness)*rc_inv)` | 相对 `x/h` 不超过 `γ14(u)`，`x=0` 时恰为零 |

因为 `h=B/2` 在正常范围内且是精确的二进制缩放，建表器两处使用的 `1/h` 与 `2/B` 是同一实数的正确舍入。cell 计数、填充和扫描按相同的 cell 划分查找坐标。

设实际整数 bin 数 `n=floor(fl(thickness/h))`，`z(x)` 表示实现计算的 cell 坐标。上表给出 `|z(x)-x/h| h ≤ γ14 L` 和 `|n-L/h| < 1+γ7 L/h`。前提保证 `γ14 L/h < 1`。每轴先取 floor，再按 n 取模，其中包括 x=L、余段折回 0 和舍入到 n 的情形。

先看精确算术。取 `n=floor(L/h)`，末尾余段与 cell 0 相连。若两个 cell 的索引在环上相距超过 2 格，其中两点间的最短周期距离至少为 `2h`。

再看有限精度。每个 cell 边界的位置变化按 `|z-x/h|h ≤ γ14 L` 计入；周期接缝处的 bin 数不确定性按 `γ7 L` 扩张。即使 `floor(thickness/h)` 在整数附近多一或少一，前述距离下界至多减少 `2γ14 L+2γ7 L`。取更宽松的 `64u L` 即可覆盖。

因此，真实单轴周期距离严格小于 `B-64u L` 时，±2 扫描一定覆盖该对原子。这里控制的是边界位置，floor 本身仍然不连续。三个轴可分别应用此结论：欧氏距离小于阈值时，每轴距离也小于阈值。

## float 比较和连续 lift

对于 `[0,L]` 内的一轴，double 相减误差至多为 `uL`。转换为 float、转换 float 盒长、最小像（MIC）的一次加减及其舍入，误差合计小于 `8vL`。当前盒和参考盒的半盒保护条件保证 cutoff 附近选择正确的 MIC 周期像。

三轴合成的距离扰动小于 `8√3 v Lmax`。距离平方需要三次平方和两次加法，截断比较还需 cutoff 的 float 平方。按 `γ5(v)` 加一次 cutoff 转换估算，折回距离单位的误差小于 `16v Lmax`。若 GPU 将 float 次正规数冲零，绝对距离余项小于 `sqrt(6*2^-126)`。由半盒保护条件及 `s=1`，此项小于 `v Lmax`。

计入 `R*=fl(d_dep-s)` 和建表/halo 半径的几次 double 加减之后，单次比较需要的距离预算小于 `32v Lmax + 64u Lmax`。该系数来自运算误差界。

**连续位移**还需要记录原子跨越周期边界的次数。对本 rank 负责的每个原子，记当前保存坐标为 `x`、参考坐标为 `q`、整数 image 为 `m`。在参考盒中，精确位移为 `U=L0*(x/L+m-q/L0)`。GPU 按轴做两个除法、两次加减和一次乘法，再计算三个平方及其和，在主机对最大平方和取平方根。

由 `|x/L|,|q/L0|≤1` 和 `|m|<10^6`，中间量绝对值不超过 `10^6+2`。逐步计入绝对误差及 `γ12(u)` 后，三轴欧氏范数的误差小于 `128u Lmax(10^6+2)`，也覆盖次正规数的绝对余项。因此，程序取的 `lift_error=1024 ε64 Lmax(10^6+2)=2048u Lmax(10^6+2)` 足够保守。

在 `sqrt` 结果上加该值，再向上取下一个 double，可得到本 rank 的 owned 位移模长上界。数学判据中的 `δ` 取所有 rank 上这些界的最大值。程序在各 rank 检查同一单调判据，再用一次 OR 汇总失败原因，无须传输全局最大位移。

image 更新和 wrap 必须由同一 kernel 执行同一个比较分支。缩放和 wrap 对已保存坐标的舍入属于真实坐标变化，计入 U。image 饱和、跨越多盒、出现非有限数或漏检 owned 原子，均不允许复用。

## 主机 slab、halo 与两跳闭包

layout 的 slab 端点由 rank/P、乘 L 和一次宽度相加组成，`distance_to_slab` 最多涉及两次加减和 `min`。`P` 是正 int 且 rank 精确转 double，端点相对精确 `rank*L/P` 的绝对误差小于 `4uL`；比较坐标、周期候选距离及迁移时 inverse×position 与乘 P 各取宽松界后，主机端 slab 与原子归属的边界位置差小于 `64u Lmax`。当端点的舍入差异改变分类时，用此界扩大所需参考距离。不同分支仍可能作出不同判断。

`d_dep=fl(Rforce+s)`、`d_coord=fl(max(fl(Rforce+Rdep))+2s)` 的下舍入及 `slab_width>=d_coord` 的舍入再各按 `8uLmax` 计入。两跳跨 slab 只发送相邻 face 的推理还要求每次 box 预检使用当前固定分解轴、slab 宽不小于 d_coord；其数值比较的不足包含在上述余量中。P=2 两面同一 peer 时发送去重且单一 wrapped 槽服务两个方向。

令实数参考边长度为 `r0`，当前 kernel 消费的边长为 `r`，每端位移不超过 δ，`α` 是实际三轴 `L/L0` 的向下界。三角不等式对任意周期像同时成立：`r0 ≤ r/α+2δ`。由于各边半径 `R≤R*`，且无论压缩还是膨胀都有

`(R+E_force)/α - R ≤ max(0,1/α-1) R* + E_force/min(α,1)`，

逐项向上舍入计算下式，严格小于 skin 时可复用：

`2δ + max(0,1/α-1) R* + E_force/min(α,1) + E_build < s`。

此式对不同 typewise 半径逐条成立。当 α>1 时，不能把 `(R+E)/α-R` 直接用 R* 端点代替：该表达式在 R 较小时更大。

独立的精确有理数对照取 `α=2, R*=10, R=0.01, E_force=0.2, 2δ=0.98, s=1`。代入后，旧表达式通过，但该边实际需要的预算超限。

现在分别给求力和建表分配误差预算，取 `E_force=E_build=512vLmax`。每条边的 cell 漏扫余量 `64uLmax`、build 的 float 距离余量 `32vLmax+64uLmax`、slab/owner 及半径舍入总计 `128uLmax` 可全部由独立的 `E_build` 支付，合计仍远小于 `512vLmax`；force 的 float 误差由独立 `E_force` 支付。因此，参考建表器会收入该边，参考 `d_dep` 内有首跳中心。

第二条边也有独立的一份严格 skin 预算。三角不等式给出两边参考长度和严格小于相应 typewise 半径和加 `2s`，而 slab/发送/分类误差已由两条边的 E 预留，因此参考 `d_coord` 包含第二跳候选。本缓存周期内，负责积分的 rank 按重建时确定的管理归属继续更新原子。只有重建才迁移原子。普通步可以改变几何归属。

这些推论要求 `R*` 覆盖 NEP 先按径向半径筛选、再按角向半径筛选，以及 ZBL 核函数实际读取的全部邻居。此外，还要求每次 halo 更新都送达对应的全局 ID，缓存中的邻居行构建成功，CPU/GPU 浮点模式符合前提。任何这些条件未证实都应保持未验收；数值差分不能替代源码和运算语义审计。
