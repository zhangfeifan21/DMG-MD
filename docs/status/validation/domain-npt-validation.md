## 2026-11-16 DN4 统计验收

这次验收覆盖单节点、5,760 原子 NEP4 金刚石碳、300 K、0 GPa 和各向同性正交全周期盒。152 条完整链完成一次最终分析，151 个注册区间按预定规则通过。检查包括并行和步长比较、独立体积响应，以及温度和压力。跨种子聚合均值的最低有效样本量为 1,035.814。[冻结的统计设计](../../../tests/npt/domain-statistics-registration.json)

| 步长配置 | 覆盖的 rank、后端和域模式 |
| --- | --- |
| 基准 | P1/HostStaged/off；P2/P4 的 HostStaged、CudaAware 各含 off、rebuild、affine |
| 半步长 | P1/HostStaged/off、P2/HostStaged/affine、P4/CudaAware/affine |

`off` 为全量复制对照，局部样本须确认 `m2a` 路径。216 原子碳 G-B、含 ZBL 的短程检查和其他材料分别有自己的证据范围。[局部 NPT 标准](../../standards/domain-npt.md) · [G-B](npt-validation.md#npt-scr-confirmation-20261104)

## 2026-11-20 单节点短程复验

另一次复验使用 4 × L20，以及 `0e8360f` 加工作树修改的 Release/sm_89 构建。条件为 5,760 原子碳、300 K、0 GPa、0.25 fs × 20 步。

## 2026-11-27 局部变盒、科学输出与跨卡重启

工单 03 在单节点 4 × NVIDIA L20 上验收，使用 Open MPI 5.0.10 和 UCX 1.20.1。双卡和四卡均覆盖 HostStaged、CudaAware，以及显式的 `rebuild`、`affine`。每个局部作业核对 GPU UUID、实际通信后端及局部模式。[复跑命令](../../../tests/npt/README.md#local-box-restart)

| 检查 | 实测结果 |
| --- | --- |
| 变盒与所有权 | 双卡、四卡分批执行，各通过 42/42 个作业。每批含 6 个单卡对照、12 个全量复制对照和 24 个局部作业。局部作业各输出 96 帧。四卡的 384 份逐 rank 快照中有 28 份为空，每帧的全局 ID 均恰好出现一次。 |
| 物理量与写入者 | 双卡、四卡的动能、势能、压力、六个 thermo 应力分量和逐原子及总 virial 与单卡的差在输出精度下均为 0。四卡 XYZ 头部应力最大绝对差为 `2.8422e-14 eV/Å³`。5,760 原子 SCR 作业中，每组仅 rank 0 以写模式打开 thermo、轨迹和 restart，次数分别为 5、4、4，含一次 thermo 表头。 |
| 初始盒与积分中的停止 | 双卡、四卡各通过 8/8 个用例。过窄初始盒在首份科学输出前以 1 退出，按原文执行单卡命令均以 0 退出。积分中第 3 步的候选条带为 15.9129 Å，低于 16 Å 下限，各 rank 在提交前退出。末个有效条带为 16.0736400097 Å，三个输出文件与独立两步对照逐字节相同。 |
| 跨卡重启 | 5,760 原子碳的 24 份来源产生 64 个目标作业，全部通过。1→2、1→4、2→4、4→2 卡各 12 个，2→1、4→1 卡各 8 个。按全局顺序核对元素、质量、盒、坐标和速度。每个目标从 0.25 fs 起逐帧与独立单卡新作业比较，共四帧。 |
